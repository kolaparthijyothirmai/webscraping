Web Scraping Project
📌 Overview
This project is a Python-based web scraping application that extracts product information from e-commerce websites using Selenium. The scraper collects product details such as product name, price, ratings, and other relevant information and stores the data for further analysis.
🚀 Features
Automated web scraping using Selenium WebDriver
Extracts product names, prices, ratings, and links
Handles dynamic web pages
Saves scraped data into CSV/Excel format
Easy-to-customize CSS selectors
Error handling for missing elements
🛠️ Technologies Used
Python 3.12
Selenium
Pandas
WebDriver Manager
